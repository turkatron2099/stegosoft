The message is encrypted in your browser before the link is ever created and never sent to Stegosoft or anyone else. Without a password, the decryption key lives entirely in the link — anyone who gets the link can read it. With a password, the key is derived from it and never included in the link at all, so the link and the password each need to be sent separately for someone to actually read the message. This is a static site with no server, so a link technically isn't destroyed after one open — on this device it'll show "already viewed" the next time, but treat it like any one-time secret: don't reuse or archive it.
