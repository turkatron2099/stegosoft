    Everything is converted right here in your browser — nothing is uploaded to Thagobyte or anywhere else. Add as many files as you want, reorder or remove them with the ↑ ↓ × buttons, then combine — each file becomes one or more pages in a single output PDF, in list order. Legacy .doc, .xlsx, and .pptx files aren't supported — only modern .docx, plain text, and image files convert reliably without a server doing the heavy lifting.
