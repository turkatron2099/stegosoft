Sprite Creator

Draw a 1-bit sprite the same way the Thagomizer VM stores one — every pixel is just on or off, and the color gets picked in-game with SET_COLOR right before SPRITE draws it, so what you paint here is shape only. Pick a preview color below just to see it clearly while you work.

.sprite line — paste directly into a .asm file

Matches docs/vm-spec.md's sprite format exactly: row-major, MSB-first, each row padded to a whole byte (ceil(width/8) bytes/row) — the same packing toolchain/text-to-sprite.js produces. Width and height are capped at 64px here since the product target screen is only 160×128 and the Gamebuino profile 80×64 — the format itself allows up to 255 either way, per the VM spec's sprite table. Palette indices 9 and 11 (marked here) are reserved for boot/menu chrome and shouldn't be used to color a sprite drawn inside a game.
